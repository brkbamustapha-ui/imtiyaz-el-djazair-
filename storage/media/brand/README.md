# Brand artwork — drop the school's own files here

Files placed here are served immediately, with no rebuild, at `/media/brand/...`.

| File | Used for |
| --- | --- |
| `logo.svg` (or `.png` / `.webp`) | Header, footer, admin panel |
| `logo-dark.svg` (optional) | A light-coloured version for the site's dark header and footer |
| `favicon.png` (optional, square, 256×256+) | Browser tab icon |
| `og-image.png` (optional, 1200×630) | Social media share card |

Nothing in this project draws the logo. If no file is present, the header shows
the school name as plain text rather than substituting a stand-in.

You can also upload the same files from **Admin → Site settings → Branding**,
which stores them here automatically.
